# 🏢 CRM Металлобаза / Metal-Depot CRM

Комплексная CRM-система учета, взвешивания, кассового баланса, нарезки и комплектования заказов металлопроката. Проект спроектирован с учетом ГОСТ стандартов РФ и коэффициентов металлургических заводов СНГ.

---

## 🛠️ Как запустить локально (macOS, Windows, Linux)

### 1. Требования
* **Node.js** (Рекомендуется v18 или старше)

### 2. Установка зависимостей
Склонируйте репозиторий на ваш компьютер и выполните установку пакетов:
```bash
npm install
```

### 3. Настройка окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте созданный файл `.env` в редакторе и настройте параметры.
> **💡 Режим умного авто-определения (Zero-Config Mode):** Если вы оставите параметры базы данных (`SQL_*`) пустыми, CRM автоматически переключится в автономный локальный режим работы! Вся бизнес-логика сохраняется во внутренней оперативной памяти Express-сервера и в `localStorage` вашего браузера.

## ⚡ Оптимизации и архитектурные решения

Мы проанализировали особенности работы приложения на локальных компьютерах разработчиков (включая MacBook на процессорах Apple Silicon M1/M2/M3) и внедрили ряд важных исправлений:

### 1. 🛡️ Отсутствие зависаний при запуске (Graceful DB Fallback)
Ранее на локальных машинах при отсутствии подключения к Cloud SQL Postgres сервер мог блокироваться или падать из-за цикла бесконечных попыток соединения (Timeout Error) в скрипте сидирования.
* **Что сделано:** Внедрена проверка `isDbConfigured()`. Если параметры базы данных не заданы, процесс сидирования (`seedDatabase()`) пропускается мгновенно без ухода в таймаут ожидания.
* На стороне сервера запущен встроенный **Mock Memory Store**, который симулирует поведение базы данных в облаке. При внесении изменений данные сохраняются в ОЗУ запущенного Node-процесса и дублируются в `localStorage` браузера.

### 2. 🍏 Исправление сборки проекта на macOS (`npx` безопасность)
На некоторых версиях macOS (особенно при кросс-платформенном монтировании файловых систем Docker/Mac) символические ссылки на бинарные исполняемые файлы в директории `node_modules/.bin` могут терять флаги исполнения или повреждаться.
* **Что сделано:** Скрипты сборки в `package.json` переведены на вызов через утилиты `npx` (`npx vite build && npx esbuild ...`). Это самый стабильный и независимый от среды путь сборки, гарантирующий вызов библиотек из локального окружения.

### 3. 💾 Решение вопросов синхронизации State (Интеграция кассовых аппаратов)
Наше текущее MVP решение отправляет полный слепок состояния клиента (full state serialization) на сервер каждые 2 секунды с дебаунсом. Для изолированной работы одной точки продаж (один холдер) это надежно, но для сопряжения нескольких кассовых терминалов это вызовет конфликты ("Last Write Wins" проблема).

#### 🚀 План миграции на Транзакционный API (Multi-Desk scaling):
Чтобы перейти от MVP к высокой отказоустойчивости при масштабировании, планируется следующая архитектура:
1. **Delta-обновления вместо полной выгрузки:**
   Каждое действие в интерфейсе кассира (создание заказа, принятие аванса, закрытие смены, отгрузка металла со склада) генерирует изолированное событие (Event-Sourcing модель).
2. **Оптимистичные блокировки и Timestamp-маркеры:**
   Добавление инкрементального поля `updated_at` (идентификатор версии строки) для каждой записи товаров и кассы для отклонения устаревших данных со стороны параллельных клиентов.
3. **Интегрированные серверные валидации ограничений:**
   Перенос проверок остатков («stock_qty») и статусов смен напрямую в базу данных в виде SQL триггеров или транзакционных проверок на уровне эндпоинтов Express (`db.transaction()`), гарантируя, что два косоура/швеллера не могут быть отпущены одному клиенту со склада дважды.

## 📐 Калькулятор Металлопроката (ГОСТ)

Помимо классических разделов кассы, в CRM интегрирован **профессиональный металлургический калькулятор**:
* **Диаметры и калибры:** Автоматический расчет фактической массы вместо теоретической по ТУ заводов (ЧМК Мечел, Северсталь, НЛМК, ЕВРАЗ).
* **Листовой и круглый прокат:** Формулы объемной геометрии с плотностью стали 7850 кг/м³.
* **Экспорт данных:** Одно нажатие копирует рассчитанный вес или метраж в буфер обмена для мгновенного переноса в карточку сборки заказа.
