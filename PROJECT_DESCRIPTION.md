# Инженерный калькулятор металлопроката и раскроя (ГОСТ)

## Обзор проекта
Это высокоточное профессиональное веб-приложение (Single Page Application) и **Progressive Web App (PWA)**, предназначенное для строителей, инженеров-сметчиков и менеджеров металлобаз. Приложение позволяет быстро выполнять точные расчеты металлопроката по государственным стандартам РФ (ГОСТ), оптимизировать раскрой хлыстов и рассчитывать листовой прокат.

Приложение полностью автономно, поддерживает офлайн-режим (Service Worker) и адаптировано под установку на Android/iOS устройства (включая готовность к упаковке через **PWABuilder** в APK/Bundle).

---

## Технологический стек
- **Фреймворк:** React 19 + TypeScript
- **Сборщик:** Vite (с плагином `vite-plugin-pwa` для генерации манифеста и Service Worker)
- **Стилизация:** Tailwind CSS v4 (монохромная индустриальная палитра, строгая геометрия с микро-радиусами `rounded-xs`, шрифты `IBM Plex Sans` и `IBM Plex Mono` с табличным выравниванием цифр `tnum`)
- **Иконки:** Lucide React

---

## Архитектура и структура файлов
- `index.html` — Точка входа, мета-теги, подключение шрифтов IBM Plex (Sans + Mono).
- `src/index.css` — Глобальные стили Tailwind и кастомные настройки.
- `index.tsx` — Рендеринг корневого компонента React.
- `App.tsx` — Главный компонент интерфейса (содержит всю логику калькуляторов и переключения вкладок).
- `gostDatabase.ts` — База данных сортамента металлопроката по ГОСТ с весами 1 погонного метра (арматура, трубы круглые и профильные, уголки, швеллеры, двутавры, листы и т.д., включая стенки от 1.8 мм и выше).
- `cuttingPlanner.ts` — Алгоритм оптимизации линейного раскроя хлыстов (минимизация обрези и расчет остатков в сантиметрах и метрах).
- `usePWAInstall.ts` — Хук для установки PWA и проверки онлайн/офлайн статуса.
- `components/PWAInstallBanner.tsx` — Плашка установки PWA, статус офлайн и модальное окно с QR-кодом для быстрого сканирования с телефона.
- `public/` — Манифест PWA (`manifest.webmanifest`), иконки (`pwa-192x192.png`, `pwa-512x512.png`, `apple-touch-icon.png`, `icon.svg`).

## Основной функционал приложения

1. **Калькулятор Метры ⇄ Вес (ГОСТ):**
   - Перевод метража (или количества штук с учетом длины хлыста: 11.7 м, 12 м, 6 м) в теоретический и фактический вес (с учетом допусков заводов-производителей, например, Мечел).
   - Обратный расчет: из массы (в тоннах или килограммах) в метраж и количество хлыстов.
   - Расчет стоимости партии по цене за тонну или за метр.
   - Кнопка копирования готовой спецификации для клиента/заказа в один клик.

2. **Калькулятор Листового Проката (ГОСТ 19903-2015):**
   - Расчет веса и стоимости стальных листов по размерам (длина, ширина, толщина в мм) и количеству штук.

3. **Оптимизатор Раскроя Хлыстов:**
   - Ввод стандартной длины хлыста (11.7 м, 12 м, 6 м, 9 м) и списка требуемых отрезков (длина + количество).
   - Алгоритм выдает карту раскроя по хлыстам с указанием остатков (обрези) и полезного расхода в сантиметрах и метрах.

4. **Справочник ГОСТ:**
   - Полная база данных металлопроката с поиском, фильтрацией и возможностью мгновенно передать выбранный профиль в калькулятор или скопировать параметры.

5. **Поддержка PWA (PWABuilder Ready):**
   - Корректный `manifest.webmanifest`, настроенные иконки всех размеров, поддержка Service Worker для работы без интернета на строительных объектах и складах.
   - Поддержка переключения тем (светлая/темная) с сохранением в `localStorage`.

## Инструкция для сборки через PWABuilder

1. Убедитесь, что проект собран:
   ```bash
   npm run build
   ```
2. Загрузите URL вашего деплоя на сайт [PWABuilder.com](https://www.pwabuilder.com/).
3. PWABuilder автоматически обнаружит манифест, Service Worker и иконки.
4. Нажмите **"Generate"** в разделе **Android**, чтобы получить готовый установочный APK-файл (или Android App Bundle для Google Play).
